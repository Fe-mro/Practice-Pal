# Practice Pal

Übungstimer für Musiker – auf Deutsch und Englisch, für Handy und Desktop.

**Live:** https://practice-pal-wheat.vercel.app

## Funktionen
- **Vorlagen nach Stil & Instrument:** Jazz-Klavier (Standard), Jazz-Klavier: Barry Harris, Jazz allgemein, Klassik-Klavier, Streicher, Gitarre (Jazz/Pop und klassisch), Blasinstrumente, Gesang, Schlagzeug, Gehörbildung
- **Übungsideen:** Bibliothek mit Skalen (u. a. Barry-Harris-Bebop-Skalen), Voicings, Vocabulary, Transkription, Technik, Rhythmus, Gehör und Repertoire. Mit einem Tipp hinzufügen.
- **Durch alle Tonarten:** pro Einheit ein Intervall wählen (kleine/große Sekunde, kleine/große Terz, Quarte, Tritonus, Quinte, kleine/große Sexte). Die Tonart wechselt per Knopf, über die Zeit verteilt oder alle N Takte.
- **Metronom:** Taktart, Betonung auf 1 oder nur auf 2 & 4, Tap-Tempo, Tempo pro Einheit, **Timing-Test mit stummen Takten**
- Timer pro Einheit, Gesamtzeit, Countdown-Töne, Bildschirm bleibt an, Feuerwerk zum Schluss
- Eigene Vorlagen werden im Browser gespeichert (localStorage)

Eine einzige `index.html`, ohne Build-Schritt. Jeder Push auf `main` wird automatisch über Vercel veröffentlicht.
